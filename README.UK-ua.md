# Interest Flow 💰📈

> Сучасний персональний трекер депозитів та візуалізатор фінансового зростання, створений для відстеження банківських рахунків, управління відсотковими ставками та спостереження за збільшенням капіталу в реальному часі.

* **Інтерактивність:** Клієнтські обчислення в реальному часі, анімації та графіки

## 🚀 Основні функції

- **Картки депозитів:** Облік окремих депозитів та банків із можливістю налаштування процентних ставок і податків.
- **Динамічні елементи:** Гнучкий інтерфейс для зміни сум та параметрів депозитів «на льоту».
- **Лічильники в реальному часі:** «Живий» тикер приросту капіталу на кожній картці та загальний зведений лічильник.
- **Історія поповнень:** Детальний журнал усіх внесків та транзакцій за депозитами.
- **Візуалізація росту:** Інтерактивні графіки прогнозування накопичення капіталу з часом.
- **Авторизація користувачів:** Захищений особистий кабінет для кожного користувача.

## 📁 Архітектура проєкту та плани

1. **Бекенд-шар (Django):**
   - Моделі для користувачів (Users), банків (Banks), депозитів (Deposits) та транзакцій/історії (Transactions).
   - В'юхи (Views) та форми (Forms) для реалізації CRUD-операцій з депозитами.
   - API-ендпоінти або передача JSON-даних у контексті шаблонів для динамічного оновлення фронтенду.

2. **Фронтенд-шар (Django Templates + Vue 3 CDN):**
   - **Django Templates:** Рендеринг основної структури HTML, макетів, панелей та початкових даних з сервера.
   - **Vue.js CDN:** Управління реактивними шарами інтерфейсу (реагування лічильників відсотків, стани карток, динамічні фільтри та анімації).

3. **Стилі та UI:**
   - Фреймворк Bootstrap CSS у поєднанні з власними компонентами для створення чистого та сучасного дизайну дашинду.
